# ExposureGAT sample data description

This file describes the example files expected in `sample/input/` and the representative files generated in `sample/output/`. The sample folders are intended to help users understand the required file structure and test the ExposureGAT workflow.

---

# Input files: `sample/input/`

The input folder contains the paired multi-omics graph files required by ExposureGAT. Each patient should have one reference sample and one transition sample, such as normal and tumor tissue.

## `X_rna_gene_features.csv`

RNA expression matrix.

- Rows: samples
- Columns: gene nodes
- Values: RNA expression values, usually log-transformed expression counts
- Row order should match the other feature matrices.

## `X_meth_gene_features.csv`

Gene-level promoter methylation matrix.

- Rows: samples
- Columns: gene nodes
- Values: average promoter DNA methylation values for each gene
- Columns should match the gene columns in `X_rna_gene_features.csv`.

## `X_cnv_gene_features.csv`

Gene-level copy-number variation matrix.

- Rows: samples
- Columns: gene nodes
- Values: copy-number alteration values for each gene
- Columns should match the gene columns in `X_rna_gene_features.csv`.

## `X_cpg_features.csv`

CpG-level methylation matrix.

- Rows: samples
- Columns: CpG nodes
- Values: CpG beta values
- CpG beta values are expected to be bounded between 0 and 1.

## `edges_ppi.csv`

Gene-gene protein interaction edge file.

Expected columns:

```text
from_idx, to_idx, weight
```

- `from_idx`: source gene-node index
- `to_idx`: target gene-node index
- `weight`: structural edge weight

For an undirected biological interaction, both directions can be included as separate directed rows.

## `edges_cpg_to_gene.csv`

CpG-gene regulatory edge file.

Expected columns:

```text
from_idx, to_idx, weight, cpg_id, entrez_id
```

- `from_idx`: CpG-node index
- `to_idx`: target gene-node index
- `weight`: structural edge weight
- `cpg_id`: CpG identifier
- `entrez_id`: target gene identifier

The data loader can add the reverse gene-to-CpG direction during graph loading so that CpG nodes can receive gene-neighborhood context.

## `map_gene_nodes.csv`

Gene-node mapping file.

Expected columns may include:

```text
entrez_id, node_idx, node_type
```

- `entrez_id`: gene identifier
- `node_idx`: node index used in the graph
- `node_type`: node class label for gene nodes

Gene nodes should occupy the first block of node indices.

## `map_cpg_nodes.csv`

CpG-node mapping file.

Expected columns may include:

```text
cpg_id, node_idx, node_type
```

- `cpg_id`: CpG identifier
- `node_idx`: node index used in the graph
- `node_type`: node class label for CpG nodes

CpG nodes should follow gene nodes in the node index order.

## `metadata_samples.csv`

Sample metadata file.

Required columns include:

```text
sample_id, patient_id, tissue_type, smoking_intensity
```

- `sample_id`: sample identifier matching the row names in feature matrices
- `patient_id`: patient or subject identifier
- `tissue_type`: sample state, such as normal/reference or tumor/transition
- `smoking_intensity`: exposure variable used for training

Additional clinical or exposure columns can be included if needed. The default ExposureGAT workflow uses `smoking_intensity` as the exposure column.

# Output files: `sample/output/`

The output folder contains representative results generated by `Analyze.py` after model training.

## `results_patients.csv`

Patient-level output table.

Typical contents:

- patient ID
- exposure value
- node contribution
- edge contribution
- patient-level transition score

This file is used to evaluate the association between exposure and patient-level transition scores.

## `results_nodes.csv`

Cohort-level node score table.

Typical contents:

- node index
- node label
- node type
- NodeDelta
- rewired degree
- weighted rewired degree
- node-exposure association score
- final node priority score / NetworkWeightedNodeScore

This file is used to prioritize molecular features across the cohort.

## `results_nodes_top200.csv`

Top-ranked node table.

- Contains the top-ranked nodes based on the final node priority score.
- Useful for manuscript summaries, pathway enrichment, and biological interpretation.

## `results_edges.csv`

Cohort-level edge rewiring table.

Typical contents:

- edge index
- source node
- target node
- edge type
- EdgeDelta
- mean attention change
- direction of attention change

This file is used to identify rewired molecular relationships.

## `results_edges_top500.csv`

Top-ranked edge table.

- Contains the top-ranked edges based on edge rewiring score.
- Useful for identifying candidate rewired network relationships.

## `results_top_rewired_edges.csv`

Top rewired edge subnetwork.

- Contains edges selected from the high-rewiring network.
- Used to compute rewired degree and network support for nodes.

## `results_patient_rewiring_burden.csv`

Patient-level rewiring burden table.

- Summarizes network rewiring burden for each patient.
- Can be used to compare rewiring burden across exposure groups.

## `results_per_patient_gene_scores.csv`

Patient-specific gene/node score matrix.

- Rows or columns represent patients and gene nodes depending on export format.
- Used for patient-specific node-score heatmaps and individual-level interpretation.

## `results_per_patient_edge_rewiring.csv`

Patient-specific edge rewiring matrix.

- Contains edge rewiring values for each patient.
- Used to examine individual-level network rewiring patterns.

## `pathway_input_node_top_network_weighted_genes.csv`

Pathway-ready gene list from top-ranked nodes.

- Contains genes selected from high-priority node scores.
- Designed for downstream pathway enrichment analysis.

## `pathway_input_edge_gene_top_rewired_edges.csv`

Pathway-ready gene list from top-ranked rewired edges.

- Contains genes involved in high-priority rewired edges.
- Designed for downstream pathway or network interpretation.

## `results_extraction_config.json`

Configuration file for post-training analysis.

Typical contents:

- scoring weights
- exposure column used for node-exposure association
- edge scoring mode
- top edge fraction
- number of top nodes and edges exported

This file documents how the output tables were generated.

# Example commands

Run model training:

```bash
python src/ExposureGAT.py \
  --data_dir sample/input \
  --out_dir sample/model_output \
  --epochs 100
```

Run post-training analysis:

```bash
python src/Analyze.py \
  --data_dir sample/input \
  --model_path sample/model_output/best_model.pth \
  --config sample/model_output/run_config.json \
  --out_dir sample/output \
  --node_delta_weight 0.80 \
  --weighted_degree_weight 0.00 \
  --smoking_assoc_weight 0.20 \
  --clustering_weight 0.00 \
  --smoking_assoc_col smoking_intensity \
  --edge_scoring_mode exposure_high \
  --top_edge_fraction 0.10 \
  --top_nodes 200 \
  --top_edges 500
```

# Notes

- The sample data are intended for code testing and file-format demonstration.
- Full manuscript-scale data may be larger and may require separate access or preprocessing.
- All scripts should be run from the repository root so that relative paths to `src/`, `sample/input/`, and `sample/output/` are resolved correctly.
